# Port Hedland draft: region references that need fixing at source

The Port Hedland report's policy sections carry prose cloned from the Kwinana
report without localisation. You asked to import verbatim, so these are now live
on the Port Hedland pages exactly as the draft has them.

**33 paragraphs across 11 indicators.** Locations are
`evidence-port-hedland.js` → indicator → paragraph index (index 0 is the
grading scale, so body prose starts at 1).

Excluded from this list as legitimate: mentions of Western Power, Synergy,
Horizon Power and "Perth-based" companies (statewide bodies), and explicit
"as with the SWIS" comparisons, which read correctly in a Pilbara assessment.
